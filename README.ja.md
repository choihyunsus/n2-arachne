# Arachne 5.0

コードと文書の検索、コンテキストの組み立て、所有者ごとのバックアップを提供します。Soul と共通の SQLite ファイルを利用し、プロジェクトとエージェントでデータを分離します。

GitHub リリースの `n2-arachne-5.0.0.tgz` を Node.js 20.19 以降でインストールしてください。Windows x64 用の文書パーサーが含まれています。他の環境では Rust 1.98 で `npm run build:documents` を実行します。

5.0 の設定、4.x からの移行、検証方法と制限は最新版の説明を参照してください。 [English](README.md) · [한국어](README.ko.md)
